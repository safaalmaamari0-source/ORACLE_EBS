===== CREATE A PROCEDURE IN EBS =====

CREATE OR REPLACE PROCEDURE SAFA_PR_EBS (ERRBUF OUT VARCHAR2, RETCODE OUT NUMBER) IS 
 BEGIN
  FND_FILE.PUT_LINE(FND_FILE.OUTPUT, 'WELCOME TO ORACLE EBS PROC..!');
 END;
 /

===== STEPS TO REGESTER THE PROCEDURE IN ORACAL EBS =====

1.REGISTER THE PROCEDURE AS AN EXECUTABLE

Responsibility:
Application Developer

Navigation:
Concurrent > Executable

Enter the following details:

Name: NAME_OF_PROCEDURE
Short Name: NAME_OF_PROCEDURE
Execution Method: PL/SQL Stored Procedure
Execution File Name: NAME_OF_PROCEDURE

Click SAVE.

To check the executable:

View > Query By Example > Enter

Enter:

Name: NAME_OF_PROCEDURE

Then:

View > Query By Example > Run

You should now see the procedure/executable details.
----------------------------------------------------------------------

==CREATE A CONCURRENT PROGRAM==

Responsibility:
Application Developer

Navigation:
Concurrent > Program

Enter the following details:

Name: NAME_OF_PROCEDURE
Short Name: NAME_OF_PROCEDURE
Application: AOL
Executable: NAME_OF_PROCEDURE
Output Format: HTML

Click SAVE.

---------------------------------------------------------------------
==ADD THE PROGRAM TO A REQUEST GROUP==

Responsibility:
System Administrator

Navigation:
Security > Responsibility > Request

Request Group Name:
NAME_OF_REQUEST_GROUP

Application:
APPL

Add the Concurrent Program:

Program: NAME_OF_PROCEDURE

Click SAVE.

---------------------------------------------------------------------
==CREATE A NEW RESPONSIBILITY==

Responsibility:
System Administrator

Navigation:
Security > Responsibility > Define

Create a new responsibility:

Responsibility Name:
NAME_OF_RESPONSIBILITY

Attach the Request Group:

Request Group:
NAME_OF_REQUEST_GROUP

Click SAVE.

----------------------------------------------------------------------
==Then assign the responsibility to one or more users==

EXECUTE THE PROCEDURE

Switch to the responsibility:

NAME_OF_RESPONSIBILITY

Then navigate to:

View > Requests

Click:

Submit a New Request

Select:

Single Request

Click OK.

Click the LOV (List of Values) to select the Concurrent Program.

Select:

NAME_OF_PROCEDURE

Click Submit.
---------------------------------------------------------------------

==CHECK THE REQUEST STATUS==

Go to the Requests window.

Click:

Refresh Data

The request status may first show:

Pending / Running

Wait until the status becomes:

Completed

VIEW THE OUTPUT

Select the completed request.

Click:

View Output

You can now see the output generated by the PL/SQL procedure.
